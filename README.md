# capacitor-eris-sosmap

CapacitorErisSosmap Capacitor Plugin

## Install

To use npm

```bash
npm install capacitor-eris-sosmap
````

To use yarn

```bash
yarn add capacitor-eris-sosmap
```

Sync native files

```bash
npx cap sync
```
